# 初期サンプルの開店待ち

大阪府の公開デモは、全曜日09:00〜17:00を計算用の仮値にしています。
訪問日が空でも、全7曜日で開店時刻が一致する駅は開店まで待機します。
曜日によって時刻が違う場合や、曜日の情報が欠ける場合は、日付なしで推測しません。

大阪駅周辺08:00発の3駅サンプルでは、最初の駅が08:41着・09:15発になります。
開店待ち19分を後続の到着・出発と帰着時刻に含め、最後の駅は09:56着・10:11発です。
60分遅らせると、最初の駅は09:41着・09:56発となり、開店待ちは0分です。

APIの `totals.wait_min` は開店待ちの合計です。移動・滞在とは区別します。
「締切に余裕あり」はスタンプ締切に対する判定であり、実際の営業確認を意味しません。
営業時間はデモ用の仮値で、実際の営業・休業日・道路状況は未検証です。

回帰確認：全曜日同一・曜日差・情報不足、初期サンプル、訪問日ありとの一致、
60分遅延、開店待ちを含む帰着時刻の表示をテストします。
