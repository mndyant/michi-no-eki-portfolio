# 車の出発エリア

手動ルート・自動提案で共通の11エリアを選択できる。現在地取得・ジオコーディング通信・緯度経度の入力は不要。
エリアの代表地点を計算APIの出発座標として渡す。駅を選んでも鉄道での移動を意味せず、周辺から車で出る概算計画。
駐車場・駅の出入口・道路上の地点への補正はしていない。移動時間は既存の座標ベース概算。

梅田は従来の大阪駅サンプルの座標（34.7025, 135.4959）を引き継ぐ。
ほかの10エリアは2026-10-07に国土地理院の[住所検索](https://msearch.gsi.go.jp/address-search/AddressSearch?q=%E5%A0%BA%E5%B8%82%E5%A0%BA%E5%8C%BA%E5%8D%97%E7%93%A6%E7%94%BA)で取得した地名の代表地点。
API応答の `geometry.coordinates` は `[経度, 緯度]`。座標を入れ替えて `frontend/src/lib/origins.ts` に固定し、利用時に外部通信しない。
