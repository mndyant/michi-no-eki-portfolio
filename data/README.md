# data/ ディレクトリについて

このポートフォリオ確認用コピーでは、第三者データを公開・配布しないため、
`data/raw/stations_kinki.json` と `data/processed/chunks.json` を含めていません。
元アプリで利用していたファイル名と件数をREADMEに残していますが、これは現在のコピーの同梱物を示しません。

## 利用条件の確認状況

元アプリの一次情報候補である国土交通省「国土数値情報 道の駅データ（P35）」は、
2026年9月12日に個別ページを確認した時点で「非商用」と表示されています。
個別ページが参照する旧約款と現行一般利用規約の関係も含め、GitHubで加工データを再配布できるとは判断していません。
政府標準利用規約（第2.0版）に準拠すると断定する旧記載は削除しました。

公開前に、次を確認してから実データを別途投入します。

1. 取得時点の個別条件と出典表示の要件
2. 加工JSON・検索チャンク・公開デモでの再配布可否
3. 応募先へ提示する用途が条件に抵触しないこと

## 現在の再現用データ

`backend/scripts/seed_demo.py` の自作・架空8駅だけを使います。駅名・位置・施設・営業時間は実在情報ではなく、
動作確認専用です。実際の旅行案内には使用できません。

## 除外するファイル

`data/raw/` の取得原本、`data/processed/` の第三者由来加工物、口コミ・写真・埋め込み、
SQLite DB、`backend/scratch/` などの生成物は公開候補へ戻しません。
